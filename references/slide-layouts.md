# Slide Layout Templates

20 universal slide layouts available as working HTML files in `templates/`. Open any template in a browser to see the structure. These are **structural patterns only** — apply the user's chosen visual style on top.

## Choosing a layout

| If your slide has... | Use template |
|---|---|
| One claim with nothing to show | Statement |
| A claim backed by a screenshot | Split |
| A screenshot that speaks for itself | Full-Bleed Image |
| Numbers that need to land | Metrics or Chart |
| A system/flow to explain | Diagram |
| A few items to remember | List (max 5) |
| A user saying something powerful | Quote |
| A definition or comparison | Definition Table |
| A transformation / improvement | Before/After |
| Milestones or roadmap | Timeline |
| Us-vs-them or option A/B | Two-Column Comparison |
| Capabilities or pillars (3-6) | Icon Grid |
| Live demo moment | Demo Placeholder |
| Credits or introductions | Team |
| Section markers | Agenda |
| A clear ask at the end | Call to Action |
| Comparing two visuals | Two Images |
| A testimonial paired with a visual | Quote + Image |

## How to use

Read the HTML template file for the layout you need. Copy its structure into your deck and replace the placeholder content. Customize colors, fonts, and spacing to match the deck's style.
